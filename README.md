# 💰 SpendSense AI – Smart Personal Finance & Student Expense Manager

**SpendSense AI** is an intelligent personal finance management web application designed to help students and individuals track their income, manage daily expenses, monitor budgets, split shared expenses, and achieve savings goals.

The application combines personal finance tracking with AI-powered financial insights to help users understand their spending habits, make smarter financial decisions, and develop better money management practices.

---

## 🚀 Features

### 1. Personal Finance Management
- Add income and expense transactions.
- Edit and delete existing transactions.
- Categorise transactions for better expense tracking.
- Monitor total income, expenses, balance, and savings.
- View monthly and yearly financial reports.

### 2. AI-Powered Financial Insights
- Analyse personal spending habits.
- Generate intelligent monthly financial summaries.
- Identify unnecessary or excessive spending.
- Suggest practical ways to reduce expenses.
- Predict possible month-end expenditure based on spending patterns.

### 3. Student-Specific Expense Management
Designed especially for students to manage everyday college and personal expenses.

- Predefined student categories:
  - Hostel Fees
  - Canteen
  - Travel
  - Books
  - Subscriptions
  - College Fees
  - Shopping
  - Other
- Record expenses shared with friends.
- Track how much each friend owes.
- Mark shared payments as settled.
- View outstanding amounts and pending settlements.

### 4. Smart Budget Limits and Alerts
- Set monthly budgets for individual expense categories.
- Monitor the percentage of budget consumed.
- Receive alerts when 80% of a budget is used.
- Display warnings when spending exceeds the allocated budget.
- Estimate whether current spending patterns may lead to budget overspending.

### 5. Savings Goal Tracker
- Create personalised savings goals.
- Set target savings amounts.
- Track accumulated savings.
- Display savings progress in percentage.
- Monitor progress towards achieving financial goals.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive user interface.
- **JavaScript** – Application logic, transaction management, calculations and interactive features.
- **Browser LocalStorage** – Persistent storage of user transactions, budgets, shared expenses and savings goals.
